## Что это за проект

«Сага о Клэнси» — браузерный рогалик-платформер на ванильном JavaScript и
Canvas 2D. **Ни сборки, ни фреймворка, ни одной зависимости**: `index.html`
подключает 23 обычных `<script>` в фиксированном порядке. Зависимости есть
только у тестов (Playwright), и только для браузерных сценариев.

Полный разбор устройства игры (мир, бой, экономика, епископы, наследники) —
в артефакте: https://claude.ai/code/artifact/acc3904f-a97d-49a7-a853-f263a6e450fc

## Как запустить

```bash
python -m http.server 8793     # из корня репозитория
# открыть http://localhost:8793/index.html
```

По `file://` игра не работает. На титульном экране есть **🛠 Тест-меню** —
мгновенный переход в бой с любым епископом или в любой тип комнаты, с полным
HP и снаряжением, без влияния на сохранение. Им удобно проверять сценарии.

После правки любого `js/*.js` нужно **поднять версию кэша** в `index.html`
(`sed -i 's/?v=52/?v=53/g' index.html`) — иначе браузер отдаст старый файл.

## Тесты

```bash
node tests/run-all.js          # 22 набора, без браузера, работают сразу
node tests/run-all.js --e2e    # + 4 сценария Playwright (нужен сервер на 8793)
```

Подробности — в `tests/README.md`. Сейчас **все 26 наборов зелёные**.

# ТЕКУЩАЯ ЗАДАЧА: SPRINT 1 — POLISH

Семь пунктов. **Сделан только первый.**

## ✅ 1. Hit flash — СДЕЛАНО и проверено в браузере

**Была за баг:** вспышка при попадании заливала врага сплошным
прямоугольником по габаритам.

**Причина:** `lctx`, который получает колбэк отрисовки каждой сущности
(`SpriteAnimator.draw`), — это **основной холст с наложенным трансформом**, а
не отдельный слой. Поэтому `globalCompositeOperation = 'source-atop'`
композитился со всем уже нарисованным фоном, а не с силуэтом спрайта.

**Решение:** `drawSpriteTinted()` в `js/spriteAnim.js` — один offscreen-буфер,
создаётся лениво, переиспользуется всеми сущностями, только растёт (никаких
аллокаций в кадре). Внутри буфера спрайт — единственное содержимое, поэтому
`source-atop` клипается по его настоящей альфе.

Переведены все пять точек тинта: GloriousGone, Bat (через sub-rect кадра
стрипа), `BossBase.drawBody` (все епископы), MirrorBoss, свечение рывка у
игрока. На основном холсте `source-atop` не осталось нигде.

Проверено скриншотами: вспышка идёт по силуэту и у рядовых, и у Кеонса.

## ⬜ 2. Аудит коллизий — НЕ НАЧАТ

Систематически проверить: игрок↔окружение, игрок↔враги, ближний бой, лук,
рывок, подбор предметов. Принцип: визуальное столкновение должно совпадать с
игровым. Хитбоксы **не раздувать** ради удобства — баланс сохранить.

**Найден реальный баг, ещё не исправлен и не подтверждён эмпирически:**
в `js/main.js` `resolveAttack()` вызывается на строке ~398, а цикл начисления
золота — на ~449 и проверяет `wasAlive && !enemy.alive`. Но `wasAlive`
считывается уже ПОСЛЕ убийства, поэтому за убийства в ближнем бою
`deathGold`, похоже, не начисляется вообще. Вероятная правка — убрать
требование `wasAlive` и полагаться на существующий флаг `goldGranted`, который
и так защищает от повторной выдачи. **Сначала подтвердить тестом.**

## ⬜ 3-5. Звук — НЕ НАЧАТ

**Важно: в проекте нет никакой аудио-системы и ни одного звукового файла.**
Проверено: ни менеджера, ни `AudioContext`, ни `.mp3/.wav/.ogg` в `assets/`.

Значит, понадобится минимальный слой на Web Audio API с процедурным
синтезом — это укладывается в философию проекта (иконки в `icons.js` рисуются
процедурно, «сочность» в `spriteAnim.js` тоже процедурная, новых ассетов не
заводили ни разу). Никаких npm-пакетов.

Нужно: (3) звук замаха с вариациями и разным характером для лёгкого/тяжёлого
оружия, (4) отдельный звук **попадания**, привязанный к реальному событию
столкновения, а не к нажатию кнопки, с троттлингом при множественных
попаданиях, (5) звук получения урона игроком с кулдауном. Инициализация
аудио — только после первого пользовательского ввода (автоплей-политика).

## ⬜ 6. Анимации смерти — НЕ НАЧАТ

**Ключевая деталь архитектуры, которую нельзя сломать:** `alive = false` —
это признак «мёртв для игровой логики». По нему считается зачистка комнаты
(`Game.enemies.every(e => !e.alive)` в `main.js`), выдаётся золото и
останавливается ИИ. Враги **никогда не удаляются** из `Game.enemies` в течение
комнаты — массив целиком заменяется при входе в следующую, так что утечек
сущностей от анимаций смерти быть не может.

Правильный паттерн уже есть у `Bat`: `alive = false` ставится сразу
(логика), а отдельный флаг `dying` + `deathHold` держит визуал, и `draw()`
его учитывает. Так же надо сделать для `GloriousGone` (сейчас исчезает
мгновенно) и для боссов. Не ломать: подсчёт зачистки, однократную выдачу
награды, невозможность убить епископа дважды, очистку клонов Лисден.

## ⬜ 7. UI экипировки — НЕ НАЧАТ

Полировка существующего UI, не новая система. Карточка должна показывать:
иконку, имя, тип, статы, эффекты, состояние «надето», сравнение с надетым.
Палитра прежняя: факельное золото `#d1b13c`, кровь `#b2453f`, холодная сталь.
Не превращать в современное мобильное меню.
