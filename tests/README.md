# Тесты

Два вида, оба без фреймворка — обычные Node-скрипты, печатающие `OK`/`FAIL`
и заканчивающиеся строкой `ALL PASS`.

## Node-наборы (`test_*.js`) — 22 штуки

Гоняют игровую логику **без браузера**. `test_env.js` — не набор, а обвязка:
она грузит обычные `<script>`-файлы игры через `node:vm` в песочницу с
заглушками DOM/localStorage, в том же порядке, что и `index.html` (кроме
`main.js` — вместо цикла отрисовки методы `Game` вызываются напрямую).

```bash
node tests/run-all.js
```

Зависимостей нет, работает сразу после `git clone`.

## Playwright-наборы (`e2e_*.js`) — 4 штуки

Настоящий браузер: клики мышью, реальный ввод, полный игровой цикл. Нужны
для всего, что живёт только в `main.js` (ввод, HUD-панели, разрешение урона).

```bash
cd tests && npm install && npx playwright install chromium
cd .. && python -m http.server 8793      # в отдельном терминале, из корня репозитория
node tests/run-all.js --e2e
```

Порт **8793** захардкожен в сценариях. Игра не работает по `file://` —
только через HTTP.

## Что покрыто

Пять епископов и их механики, сохранение побед между смертями, циклы/NG+,
наследники и все пять архетипов, ближний бой, лук и физика стрел, отражение
стрел Блэрифейс во второй фазе, спецкомнаты (сокровищница, элита, испытание,
кровавый завет, тайник), экономика и цены улучшений, автоэкипировка,
тест-меню, hit-flash.

## Если добавляешь набор

Файл должен сам печатать `ALL PASS` в конце и выходить с кодом 0/1 —
`run-all.js` ориентируется именно на это. Путь к корню репозитория брать как
`require('path').resolve(__dirname, '..')`, не абсолютным.
